# Data-free analytic digit network

The network compares the input with generic mathematical pen-path models of the ten digits. The paths are written directly as lines, cubic Bezier curves, and oval loops, and a fixed random seed supplies prescribed variations in width, slant, curvature, and stroke thickness. All constants describe digits in general; no training image, crop, descriptor, class average, or other data-derived quantity is used to construct a weight.

Fixed Gaussian convolution and contrast normalization provide a smoothed shape channel, and eight analytic Sobel orientations with spatial pooling provide a stroke-direction channel. ReLU-based ink saturation and local max pooling provide ink-coverage channels. An unrolled morphological circuit propagates background reachability from the frame border to detect enclosed regions; missing holes are not penalized because handwritten loops may be open. For each analytic model, dense layers compute normalized shape and direction correlations, coverage of its expected strokes, a penalty for unexplained ink, and evidence from enclosed regions; max pooling selects the best of 8,192 geometric variants for each class. Every weight is calculated directly from these formulas, with no gradient descent, fitting, or optimization, including on synthetic examples. `build.py` reads no files and writes `network.json` and `weights.npz` using only Python and NumPy.

Exactly five labeled checks were run with the official runner. The final network achieved 87.19% accuracy on the first 10,000 official training examples; this is a training-set diagnostic, not a held-out result. The final network has 96,749,342 float32 weight entries. `check_network.py` passed, and `check_rebuild.py` passed with zero relative difference; the standalone builder is 17,081 bytes. The earlier checks informed qualitative design revisions, but no image measurements, image-derived statistics, learned coefficients, or fitted class biases were incorporated into the weights.
