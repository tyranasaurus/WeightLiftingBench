# Hand-designed traffic-sign network

The network combines fixed luminance/colour adaptation, clipped opponent-colour features, and analytical vector models for all 43 sign classes. Its artwork is generated from circles, polygons, lines, Bézier curves, hand-specified numeral strokes, and schematic arrows and pictograms; a fixed grid of translations, scales, aspect ratios, rotations, and four drawing styles provides geometric tolerance. A second branch bilinearly samples ideal circular or triangular sign interiors, normalizes each candidate's contrast independently, and correlates it against the same data-free artwork; border/colour evidence and interior evidence are combined at matching geometries before maximum pooling produces 43 class scores.

All 114,094,134 float32 weight entries are constructed by formulas and explicitly written general-purpose sign geometry in `build.py`. No training images, descriptors, class averages, fitted parameters, external fonts, or downloaded weights are used to produce them. Training images were viewed only in a class montage, and exactly five labelled evaluations were performed using the supplied runner to diagnose structural issues; there was no automated search or fitting. The final permitted check measured 37.85% accuracy on the 39,209 training images, which is not a held-out accuracy estimate and does not demonstrate superiority over either comparison baseline.

Reproduction: `python3 build.py NEW_FOLDER` writes `NEW_FOLDER/network.json` and `NEW_FOLDER/weights.npz` using only Python, NumPy, and this source file, without reading data or assets.
