I used a hand-designed, multiresolution template-correlation network. A fixed Gaussian kernel smooths the input. The readout combines full-resolution correlation, 2x2-pooled correlation, and a second view that thresholds and renormalizes both bright-hand and dark-hand interpretations of the image. Each class has the same number of templates, and the network takes the best pose and polarity independently for each class.

Every template is drawn procedurally in `build.py` from general ASL hand anatomy: a palm, wrist, articulated finger capsules, class-specific thumb placement, and anatomical creases. The drawings cover left/right hands, small rotations and translations, two crop scales, and ten independently seeded anatomical proportion variants. Each drawing is fitted using only its own bounding box and each feature template is normalized individually. Gaussian filters, thresholds, shape weights, and all other constants are written directly in the source. No training image, label, fitted statistic, or learned weight is used, and `build.py` reads no input files.
