# Analytic traffic-sign network

This is a 27-layer, fixed-weight network with 40,916,680 float32 weight entries, below the 120,000,000-entry limit. It first reshapes RGB into one spatial sheet and applies the allowed normalization operation, preserving relative channel information while reducing sensitivity to exposure. Fixed opponent-colour projections and pairs of ReLUs yield clipped luminance, red, blue, and yellow channels; fixed Sobel derivatives, rectification, and local integration supply eight oriented-edge channels.

The recognition filters come entirely from procedural ideal road-sign geometry: circles, triangular and octagonal borders, a yellow diamond, monoline numeral strokes and Bezier curves, arrows, and approximate pictograms. Each class has 90 formula-generated combinations of size, aspect ratio, rotation, and artwork style, with max pooling across one-pixel translations and artwork variants. A parallel branch scores eight coarse sign families and adds a manually specified family score to each corresponding class. These synthetic stencils are direct geometric constructions, not templates extracted from photographs and not parameters learned from synthetic examples.

`build.py` reads no files and uses only its source, NumPy, and the standard library to write `network.json` and `weights.npz`. No gradient descent, regression, class averages, feature banks, clustering, external fonts, pretrained parameters, or image-derived weights were used. The training set was used for the permitted visual overview and five labeled checks only; each check used the same fixed, label-independent slice (every eighth image, 4,902 images). Manual revisions addressed general geometric and numerical shortcomings; no automated parameter search or fitting was performed.

The five checks reported 36.96%, 36.25%, 36.64%, 36.39%, and 44.68% accuracy respectively. The submitted network is the final checked version, unchanged after check five. These are development-subset results, not held-out accuracy: the hidden test set and the two comparison answers were unavailable. Complex warning pictograms, cancellation signs, and some similar speed digits remain important limitations.
