The ten class models start with pen paths specified by hand from ordinary digit-writing conventions. The data-free builder renders fixed-seed variations in knot position, slant, curvature, proportions, taper, and nib width, then tabulates their geometric descriptors; it does not read examples or fit parameters. For each input, the recognizer removes most of the shear and normalizes the size before comparing ink density and oriented edges. It also compares enclosed white space at several ink thresholds, then verifies the most plausible classes by matching local patches with a penalty for neighboring patches moving in different directions. All comparisons are per image. The coarse comparisons use quantized vectors with exactly representable dot-product sums, so changing the batch layout does not change those sums.
