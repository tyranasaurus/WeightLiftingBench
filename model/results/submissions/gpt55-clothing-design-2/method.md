The network is a hand-built template matcher.  It first normalizes the input image per channel, then applies one dense layer whose rows are synthetic 28 x 28 clothing silhouettes made from simple geometric primitives (rectangles, polygons, ellipses and line segments) for the ten named classes.  The dense outputs are reshaped as class-by-template scores, max-pooled within each class, and reshaped to the final 10 class scores.

The weights are produced entirely by `/app/out/build.py` from fixed formulas and a fixed random seed.  Each generated silhouette is normalized by itself alone before being written as a dense-row template; the constants and class offsets were chosen by hand from general visual expectations about shirts, trousers, shoes, bags and boots, with no fitting or stored training-image values.
