The network combines five hand-designed kinds of evidence: multi-scale greyscale object templates, raw colour object templates, coarse colour-scene templates, spatial colour histograms, and coarse Sobel edge layouts. Object and scene templates come from analytic drawing routines using general knowledge of each class (for example, wheels and a cab for a truck, a hull and mast for a ship, and body/head/leg shapes for animals). Every generated drawing is normalized independently; no statistic is shared across drawings. The colour branch assigns pixels softly to a fixed hand-written palette and compares spatial histograms with centred, hand-written class layouts. Response normalization is performed within each input image, not from a dataset. All weights and gains are fixed formulas or hand-chosen constants with a fixed random seed; no training images, labels, optimization, regression, or fitted statistics are used by `build.py`.
