# Hand-constructed geometric and contextual network

The network has 70 layers and 50,369,825 float32 weight entries, below the 120,000,000-entry limit. Its front end uses analytic luminance derivatives, unsigned orientation-selective edges at two resolutions, dark-center and tyre-ring filters, bounded RGB colour predicates, and instance normalization. Dense layers compare those features with 60 schematic object models built from explicitly programmed ellipses, polygons, and line segments: wings and fuselages; wheeled vehicle bodies; bird bodies and beaks; animal faces, torsos, and limbs; frog bodies; and boat hulls and superstructures. Formulaic mirroring, rotation, translation, and scaling yield 720 poses per class. Maximum pooling selects a pose, and a hand-written contextual rule table adds habitat, material, and texture evidence.

Every submitted number is produced by `build.py` from its own source and mathematical formulas. The program opens no input files and performs no training, optimization, regression, prototype extraction, or statistical estimation from dataset images or labels. Normalizing a generated geometric template uses only that synthetic drawing; instance normalization of an input is an ordinary network operation. A class-ordered montage was viewed for qualitative orientation, but no pixels, coordinates, outlines, measurements, or descriptors from those photographs were copied into the builder.

Exactly five labelled evaluations were made through `/app/run_network.py`. The first four used the same 3,000 training examples and returned 24.73%, 21.80%, 24.80%, and 24.20%, respectively, during structural revisions to the hand-designed feature computations. The final submitted version was checked on 7,000 different training examples and obtained **22.40% accuracy**, corresponding to a normalized task score of approximately **0.1378 on that check only**. That final version is retained, not a retrospectively selected highest-scoring variant. No hidden-test evaluation or comparison-system result is available, and superiority over either comparison system is not claimed.

Reproduce the answer with `python3 build.py OUTPUT_DIRECTORY`. The output files are `network.json` and `weights.npz`; no data or auxiliary file is required.
