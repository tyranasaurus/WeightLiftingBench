The network compares each normalized photo with procedural drawings, using both brightness patterns and oriented contours. For example, a lorry model includes a box, a cab, and wheels; an animal model can include a torso, head, and articulated legs. Max pooling allows changes in pose, scale, and position. A foreground branch compares each candidate silhouette against color changes from the sides of the image. Other branches score landmarks such as wheel pairs and eyes, and test scene layouts such as a hull above water or a car body above pavement. The readout combines these with hand-specified evidence about color, texture, straight lines, and symmetry. All geometry, filters, thresholds, and class votes are defined in `build.py` from general object and scene knowledge; none are fitted to photographs or labels.
