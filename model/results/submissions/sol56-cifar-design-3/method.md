The network is a deterministic, hand-designed visual classifier. One branch computes smooth colour, intensity, and colour-opponent threshold maps with Gaussian kernels and average-pools them into an 8×8 layout; a second branch computes analytic oriented gradients, bars, centre-surround spots, and corner filters and max-pools detections into the same layout. Disjoint channel ranges allow the branches to be combined, after which a hand-written dense rule layer scores general object cues such as airplane wings in sky, automobile/truck wheels and horizontal bodies, quadruped bodies and legs, frog green colour and paired eyes, and ship hulls, water, horizons, and decks. Every number comes from formulas or general class knowledge; no training image, image statistic, optimization, fitting, or gradient descent was used, and `build.py` reads no files.
