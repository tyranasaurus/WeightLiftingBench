# Method

I built a small hand-designed network rather than fitting weights from the training set. The image is first average-pooled from 128 x 128 to 32 x 32, then passed through a dense bank of analytic filters: round/concentrated apertures, red and blue colour contrasts, disk-extension contrasts, elongation and thin-edge-on masks, bar masks, logarithmic spiral masks with two pitches and both handednesses, two-lobe merger masks, and one-sided/asymmetric clump masks. Each filter family is evaluated over fixed hand-chosen scales and orientations and max-pooled to make the network insensitive to galaxy size and position angle.

A second dense layer forms hand-written morphology combinations such as smooth-round, smooth-elongated, edge-on without bulge, edge-on with bulge, barred spiral, tight spiral, loose spiral, disturbed, and merging. The final dense layer is a manually calibrated rule table mapping those interpretable responses to the ten output classes. All masks, thresholds, and score weights are generated from formulae in `build.py`; no training images, labels, class averages, fitted statistics, patches, or learned parameters are used to create the weights.
