The builder uses a fixed seed to draw 3,200 silhouettes per class from hand-written geometric patterns: bodices and sleeves, skirts, trouser legs, strapped soles, boot shafts, and bag bodies with handles. It encodes each drawing as pooled coverage, four contours, and an aspect ratio; it does not read photographs, labels, or other files. At prediction time, the program extracts the same measurements from each item and compares them with the drawings. Hand-written rules distinguish similar shapes using evidence such as a collar above the shoulder line, a center-front fastening, a curved shirttail, or a gap beneath a sandal strap.

I visually inspected labeled contact sheets and used the five permitted sandbox checks. The final check, on a separate batch of 10,000 training images, classified 7,465 correctly; this is not a held-out test result. Both the format and data-free rebuild checks passed.
