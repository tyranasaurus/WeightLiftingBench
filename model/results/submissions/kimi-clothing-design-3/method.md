The network is a hand-drawn, multiscale shape matcher. I wrote general garment models for each class: short sleeves and a neck opening for T-shirts, separated legs for trousers, hanging sleeves for pullovers, flared skirts for dresses, lapels and an open front for coats, several heel/strap arrangements for sandals, low sole-and-upper profiles for sneakers, collars and button plackets for shirts, loop handles for bags, and tall shafts for ankle boots. Each of 120 variants per class is an independent drawing; its normalization uses only that drawing.

A soft threshold extracts silhouette ink, which is evaluated at 28x28, 14x14, and 7x7 resolution, alongside a 7x7 grayscale branch. For a template with ink mass T, image ink mass A, and intersection I, each branch computes I/T - |A-T|/(2T), a Dice-like overlap with an explicit size-mismatch penalty. The best template in each class is selected and the four equally weighted branch scores are added. All shapes, thresholds, and weights are generated by build.py from formulas and general class knowledge; no training examples, labels, fitted statistics, or external files are used.
