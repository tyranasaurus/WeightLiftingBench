# Data-free digit network

The weights are constructed from hand-written, parametric pen paths: ovals, straight strokes, cubic Bezier curves, and a figure-eight curve. A fixed-seed generator varies these general-purpose drawings in width, height, slant, curvature and writing style. None of these paths, parameters or weight fields is obtained from a training image, image descriptor, class average, optimization procedure or fitted statistic.

The network combines contrast-normalized correlation with these analytic drawings and bidirectional stroke-proximity scores. The proximity branch normalizes foreground mass using a fixed signed-pair normalization circuit and allows small local shifts of four horizontal portions of each pen path. Max pooling selects a compatible drawing for each digit. A separate fixed morphological circuit floods background from the image boundary; background not reached by the flood supplies large-hole, upper-loop and lower-loop evidence through a small hand-written topological score table. All computations use only the permitted neural-network operations.

`build.py` reads no input files. It constructs all float32 tensors from the geometry and constants in its own source and writes `network.json` and `weights.npz` to its sole command-line argument. Training examples were viewed only to understand handwriting styles; inference checks used only the supplied labeled checker, with exactly five calls on the first 5,000 training examples. The final check gave 75.26% accuracy; this is a training-subset diagnostic, not a held-out accuracy claim. The final network has 111,432,231 weight entries, within the 120,000,000 limit. There was no gradient descent, synthetic-data training, fitted readout, or storage of example-derived quantities.
