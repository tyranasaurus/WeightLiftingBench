`build.py` constructs the static ASL handshapes from finger lengths, joint bends, finger spread, thumb placement, and palm and wrist shapes. It projects both articulated 3D hands and view-centered geometric drawings with a depth buffer, directional shading, and contact shadows; a fixed seed varies anatomy, pose, lighting, and framing. At prediction time the program estimates a soft hand mask from border connectivity and local contrast, then compares several alignments using pooled silhouette, oriented-edge, narrow-ridge, and signed crease descriptors, supplemented by Fourier magnitudes of the silhouette's row and column extents. All reference descriptors come from the procedural renderer: no photograph, image measurement, fitted weight, or class statistic is included in the build. The official training set was used only for visual inspection and logged checks.
