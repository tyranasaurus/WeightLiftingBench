I used a hand-written multi-scale detector network. The first convolution makes fixed colour and edge channels: warm/skin-like colour, dark, light, medium brightness, and oriented luminance edges. Three parallel scales then apply the same six large templates over the image: a small face, a broad close-up face, a head-and-shoulders pattern, a standing body silhouette, a two-head/group pattern, and a generic human-like silhouette. Each template is built from typed geometric primitives such as ellipses, capsules, and edge rings rather than any statistics from the training set.

Each scale keeps only its strongest match with global max-pooling, and the final dense layers sum those evidence scores into class 0 vs class 1. The weights are generated entirely from code in build.py so the answer can be rebuilt without the data.
