The network is a hand-built multi-branch rule system using only analytic filters and generic object knowledge.  It pools the image to an 8 x 8 colour grid, applies fixed colour threshold detectors, normalized Sobel/line/spot filters, local colour/line part filters, and a bank of low-resolution semantic templates for generic planes, vehicles, ships, animal faces, quadrupeds and frogs.  The final layer adds the branch scores for the ten CIFAR-style classes.

All weights are generated by /app/out/build.py from formulas: Gaussian blobs, soft rectangles, simple ellipses, line masks, hand-chosen RGB colour directions, and hand-drawn generic shape templates.  No weight stores or is derived from any training image, crop, patch, descriptor, label statistic, regression, clustering, or gradient descent.  I used the allowed checks only to detect coarse score-calibration failures and then adjusted class-level hand biases/scales.
