The network uses three kinds of evidence: scene context from regional color and texture, local arrangements of visual parts (including wheel pairs and eyes above a muzzle), and geometric silhouettes. The silhouette branch compares both oriented edges and inside-versus-outside color at several scales, reflections, and positions. A hand-written ReLU rule bank combines these cues into ten class scores; for example, a long horizontal hull is stronger evidence for a ship when the lower scene also looks like water.

`build.py` generates the weights entirely from analytic filters and pooling masks, canonical outlines drawn from general object geometry, and hand-set thresholds and rule coefficients. The training set was viewed qualitatively and was not used to calculate, fit, or select weights.
