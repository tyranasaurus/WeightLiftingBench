# Analytic galaxy morphology network

The network uses fixed smoothing, centred apertures, rotation asymmetry, radial non-monotonicity, colour contrasts, and multi-scale shape moments. Its main branches compare normalized light distributions with formula-generated, blur-convolved models: Sersic-like ellipses, exponential disks with compact bulges, projected bars, logarithmic spiral arms in both winding directions, and pairs of nuclei. Max pooling marginalizes declared grids of scale and orientation; ReLU arithmetic and channel normalization implement continuous hand-written morphology rules and dimensionless ratios, producing ten class scores in the requested order.

Every weight is generated from mathematical formulas or explicitly hand-chosen constants in `build.py`. The builder reads no files, uses no training examples or example-derived descriptors, and performs no optimization, statistical fitting, or parameter search. The training data were used to view one class gallery, print array information and class counts, and conduct exactly five labeled diagnostic calls to the official runner on one fixed random 2,000-image subset; class counts were not used in the weights. Between checks, the analytic models and qualitative rules were revised manually, not fitted.

The submitted network has 389 layers and 110,961,549 float32 weight entries. The fifth and final diagnostic check achieved 0.3195 accuracy (normalized task score approximately 0.2439) on that training subset; this is not an unseen-test estimate. Round smooth galaxies, mergers, intermediate smooth galaxies, and thin edge-on systems are recognized to varying degrees, while disturbed, cigar-shaped, and bulged edge-on systems remain substantial weaknesses. Neither performance on the hidden images nor superiority to the two comparison methods has been established.
