# Method

## Architecture
A feed-forward "neural program" built only from the allowed ops (59 layers, ~1.06 M weight entries, ~16 k non-zero):

1. **Masks** (1x1 convs + relu pairs): a silhouette mask (grey ramp 0.10 -> 0.20) and a "deep" mask (0.03 -> 0.07) that excludes only true background.
2. **Hand-written detectors** (small convs): interior pixels (>= 8 of 9 neighbours lit), 1-px thin lines, holes at two scales (background pixel with lit pixels on both sides), horizontal top edges, a centre valley / ridge detector on the grey image (open coat front or seam / bright shirt placket), a lapel (deep V) detector, and an interior-gated horizontal-gradient texture map.
3. **Pools**: max over 4-row and 2-row bands (band widths), over 4-column bands (band heights), over whole rows / columns (height, width), plus a sliding 7-row max that bridges gaps to estimate vertical extents.
4. **Feature stage**: one dense layer per map, added together, giving silhouette measurements (height, width, band widths/heights, top-third left/right masses, flare, sleeve drop, waist, cuff gap, leg gap, hole counts, edge lengths, solidity, emptiness ...).
5. **Indicator ramps**: soft thresholds `clip((x - t)/w + 0.5, 0, 1)` built from relu pairs; every `t`, `w` is a hand-chosen pixel count reasoned from the geometry (longest side scaled to 28, item centred, shoes point left).
6. **Rules**: AND-gates `relu(sum of indicators - (n-1))` encoding hand-written rules per class (e.g. "tall, narrow, waistband-like top -> trousers"), some carrying small evidence terms inside the gate (e.g. the long-sleeved-top cell: centre seam / lapel -> coat, bright placket -> shirt, otherwise pullover; the low/wide cell: solid + heel rise -> sneaker, strappy / thin / empty box -> sandal, tall one-sided shaft -> boot, symmetric and taller -> bag).
7. **Scores**: weighted sum of rule activations.

## How the weights were produced
All weights are generated by formulas in `build.py` from constants chosen by hand. No training, fitting, statistics of the training images, or copying of image content was used. The training set was only viewed (PNG grids) to refresh general knowledge of what each class looks like; the network was unit-tested on synthetic silhouettes drawn from geometric primitives (rectangles, L-shapes, thin lines) and then checked 5 times on random training subsets via `run_network.py` (accuracies 54.5%, 59.2%, 58.2%, 56.8%, 57.9%), with rules adjusted by hand between checks based on the confusion tables. The final check (8000 images) gave 57.9%; its confusion table shows the remaining weak spots: long-sleeved tops leaking into the dress class through the "hem wider than shoulder span" rule, and sandals split between sneaker, boot and bag. Trousers, sneakers, bags and ankle boots are each above 80%.
