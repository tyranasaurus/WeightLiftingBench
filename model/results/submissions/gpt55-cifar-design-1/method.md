This is a data-free, hand-engineered classifier.  The network first averages the image to 16 x 16, applies 52 fixed 3 x 3 analytic filters, rectifies them, averages to an 8 x 8 feature grid, and uses one fixed dense readout for the 10 class scores.

The convolution filters are not trained: they are brightness/darkness thresholds, colour-opponent axes, Sobel-like edge filters, line/ridge filters, and simple spot/ring filters generated from formulas.  The dense layer is a hand-written rule table over smooth spatial masks: airplanes and ships reward sky/water and straight horizons; cars and trucks reward low rectangular/wheel evidence; animals reward central texture, earth/green colours, and leg/body regions.  The only use of the training set was visual inspection/simple metadata plus five allowed full-network checks; no training image, measured crop, statistic, learned readout, regression, clustering, or gradient descent was used to produce any weight.
