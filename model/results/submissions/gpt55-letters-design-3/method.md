The network uses only hand-written weights generated by `/app/out/build.py`.  I represented each ASL letter by a simple analytic drawing made from ellipses and capsules (palm, wrist, extended fingers, curled fingers, OK rings, sideways pointing fingers, and a few generic crease strokes).  The build script creates shifted, scaled, and polarity-flipped versions of those drawings, plus fixed Gaussian derivative / ridge filters, then writes a network with two template-matching branches: a raw normalized-image matcher and an edge/ridge matcher pooled to 14 x 14.  Each class score is the maximum over its hand-coded variants, followed by a small manually chosen class-to-class calibration layer to reduce broad closed-hand/O-shape dominance.  No training images or image-derived measurements are read by the build script; the numerical weights come from these formulas and hand-written ASL shape descriptions only.
