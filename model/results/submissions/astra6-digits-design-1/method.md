# Hand-designed digit network

The network uses analytic stroke-direction filters, multiscale max-pooling to approximate distance to ink, and a bank of 5,120 procedural pen models per digit. Each model is constructed from explicitly typed generic line segments, cubic Bezier curves, or ellipses, with deterministic low-discrepancy variations in width, slant, curvature, position, and loop proportions. Its score combines missing-stroke, extra-ink, and stroke-direction agreement; max-pooling selects the strongest model within each class. A small secondary branch implements background flood filling and hand-written rules about upper, lower, and central holes.

Every weight is calculated by `build.py` from these geometric constructions, analytic filters, fixed arithmetic approximations, and manually specified rules. The script reads no files, uses no downloaded weights or fonts, and performs no training, fitting, clustering, or optimization. Ink-mass normalization is implemented with explicit piecewise-linear reciprocal and multiplication formulas. No training image, patch, descriptor, measurement, or class statistic is stored in the weights.

Five labeled checks were performed exclusively through `/app/run_network.py`: the first four used the first 3,000 training examples and obtained 77.80%, 77.10%, 86.27%, and 90.60%; the final unchanged submission obtained **90.75% on training examples 10,000 through 19,999** (zero-based indexing), which were not used in the preceding checks. A montage of the first twelve examples of each class was viewed for qualitative style understanding only. Revisions addressed construction flaws and general handwriting variations; there was no parameter search or fitted readout. The hidden-test accuracy and the two comparison systems' results are unknown.

The final network contains **100,523,871 float32 weight entries**, below the 120,000,000-entry limit, and outputs ten class scores. `check_network.py` validated all layer shapes and weights. The required `check_rebuild.py /app/out` also passed under its isolated, unprivileged execution: the 20,064-byte build script reproduced both answer files with maximum relative weight difference 0.0. Run `python3 build.py NEW_FOLDER` to recreate `network.json` and `weights.npz` without any data or supporting files.
