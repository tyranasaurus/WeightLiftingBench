# Analytic clothing network

The network uses only hand-designed operations and weights: piecewise-linear foreground detection, contrast normalization, morphological pooling, and geometric silhouette matching. Generic polygons, ellipses, and strokes describe garment bodies and sleeves, separated trouser legs, flared skirts, shoe soles and uppers, sandal straps, and bags with handles. A fixed seed samples independently specified geometric variations; 1,024 analytic silhouettes per class become dense-layer squared-distance scores, and max pooling selects each class's strongest match. These are generated shape models, not training images, traces, class averages, or stored image descriptors.

Additional fixed branches measure sustained front openings, collar ridges, two-axis plaid lines, interior footwear gaps, leg separation, and long sleeves. Their bounded contributions and all proportions, tolerances, and coefficients were chosen by hand. No gradient descent, regression, clustering, objective optimization, or fitting was performed, including on the generated shapes. The builder reads no files and writes the architecture and float32 weights using only its own source and NumPy.

Training examples were viewed in a class montage, and five labeled checks were run through the supplied evaluator on the same first 6,000 training images. Qualitative failure modes informed successive hand-designed revisions; no training-image measurements or computed class statistics supplied weight values. The submitted final network has 95 layers and 4,771,291 weight entries. Its fifth and final check obtained 64.70% accuracy. The final plaid cue increased confusion among garment classes; this limitation remains in the submitted version. No held-out accuracy or superiority over either comparison system has been established.
