The network is a generative, multiscale stroke-template classifier. Each digit class has 4,000 templates rendered entirely from typed pen paths: ellipses, Bezier curves, line segments, loops, and optional bars or serifs. A fixed-seed generator varies ordinary handwriting properties such as pen width, aspect ratio, slant, smooth elastic deformation, loop proportions, and rasterization placement. No training image, label, crop, class statistic, or fitted parameter is used.

Each rendered path is blurred with a fixed Gaussian and interpreted as a per-pixel Bernoulli ink-probability model. A dense layer computes its affine log-likelihood exactly. The network evaluates these likelihoods at 28x28, 14x14, and 7x7 resolutions, combines them with fixed weights of 0.50, 0.35, and 0.15, and uses spatial max pooling to select the best template within each of the ten classes. The final training-set check gave 71.54% accuracy; this remains below what a strong trained network would ordinarily achieve.
