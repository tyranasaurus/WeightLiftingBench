# Analytic person-presence network

This network uses only hand-designed colour and geometric cues: linear-RGB skin-colour half-spaces, normalized luminance, Sobel orientation energies, schematic bilateral face-region contrasts, soft head/neck/shoulder/torso contour stencils, and shirt-region consistency gates. A four-level average-pooled pyramid searches over position and head size; ReLU rule circuits combine the cues, including exact minimum gates for conjunctions, and maximum pooling selects the strongest detection. The two final outputs are a fixed no-person reference score and a person-detection margin. Contour cues support colour detections rather than independently deciding that arbitrary textured objects are people; a more restrictive achromatic frontal-face route handles some grayscale images.

Every weight is computed by `build.py` from explicit constants, Gaussian formulas, generic geometric drawings, or fixed arithmetic wiring. There are no pretrained parameters, learned weights, training-image statistics, image-derived templates, or stored examples. Training images were viewed only for permitted qualitative inspection, and labelled evaluations use the provided `run_network.py`. Five checks were used on a fixed random 2,000-image subset; the final network achieved 60.15% accuracy (confusion matrix, true-label rows: [[686, 344], [453, 517]]). This is an in-sample diagnostic, not a held-out performance estimate or evidence of beating either comparison system. The final network has 116 layers and 702,213 float32 weight entries. Structural validation passed, and `check_rebuild.py` reproduced `network.json` and `weights.npz` with zero numeric difference.
