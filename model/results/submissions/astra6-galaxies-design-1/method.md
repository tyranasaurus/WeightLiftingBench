# Analytic galaxy-morphology network

This is a fixed, hand-designed network, not a trained network. It averages neighboring pixels, subtracts an annular sky estimate computed separately from each input, and examines the central galaxy with analytic Sersic ellipses, bar-plus-disk models, double-nucleus models, logarithmic-spiral filters, quadrupole moments, rotational asymmetry, texture, and red/blue aperture photometry. Max pooling handles template orientation and scale; paired-channel normalization approximates flux ratios, and explicit piecewise-linear rules produce the ten class scores. All 21,621,603 weight entries are generated from formulas, geometric grids, and hand-written constants in `build.py`; the builder reads no files and uses no training examples, fitted coefficients, or pretrained weights.

Training images were viewed as a contact sheet, and five labelled checks were run only through the supplied runner. Checks 1 and 2 used a fixed 200-image diagnostic subset (23.5% and 34.0% accuracy); checks 3–5 used a fixed 1,000-image subset containing those 200 images (30.0%, 41.0%, and 39.7%). The submitted network is the final checked design, not a rollback selected for the highest diagnostic accuracy. These are development checks, not independent estimates of held-out performance: the final design remains weak on disturbed, cigar-shaped, and barred galaxies, and there is no evidence that it beats either comparison system.

Reproduce the submission with `python3 build.py OUTPUT_DIRECTORY`. The program writes only `network.json` and `weights.npz` into that directory.
