# Hand-designed clothing-shape network

The network has 72 layers and 8,100,557 float32 weight entries. It builds a brightness-normalized soft foreground map and a morphologically thickened version, then compares their pooled cells with 2,048 procedural silhouettes per class. These silhouettes are drawn from polygons, ellipses, and strokes describing generic torsos and sleeves, two trouser legs, dress skirts, shoe uppers and soles, sandal straps, boot shafts, and bag bodies and handles. A fixed random seed supplies variations in the drawing parameters and pose; no drawing is taken from, traced from, or fitted to an image. Affine template scores implement negative squared distances with the common input-dependent term omitted, and max pooling selects the best drawing for each class.

Additional fixed branches use finite-difference filters and hand-written rules for leg separation, open footwear, sleeve length, persistent front openings, fabric detail, and collar edges. All constants come directly from the source and general geometric assumptions. The build program reads no input files, uses no optimization or fitting, and needs only Python and NumPy.

Exactly five permitted labeled checks were run using `/app/run_network.py`. The first four used the first 10,000 training examples; the final check used all 60,000 training examples and measured 64.13% accuracy. Revisions were manual changes to the generic drawings and qualitative rules, not estimated statistics, fitted coefficients, or a search over scored candidates. The final version is submitted without selecting a previous version. Its main weakness is confusion among pullovers, coats, and shirts; held-out accuracy and performance relative to the comparison systems are unknown.
