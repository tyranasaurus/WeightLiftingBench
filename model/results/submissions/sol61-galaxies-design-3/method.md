# Fixed analytic galaxy-morphology network

The 168-layer network uses only the permitted operations and has 68,794,129 float32 weight entries. Its filters and arithmetic are constructed from coordinate formulas: Gaussian seeing filters, robust sky subtraction, relative isophotes, Gaussian-weighted quadrupole moments, clipped color contrasts, 180-degree rotational asymmetry over fixed trial centers, extended-core bandpass filters, logarithmic two-arm correlations, and seeing-broadened ellipse models. Fixed norm constructions implement approximate flux ratios, and a uniform piecewise-linear square formula implements multiplication for scale adaptation. A hand-written fuzzy rule table produces the ten class scores.

All weights are generated by build.py from analytic expressions and general morphological assumptions. The builder reads no input files, uses no training examples or pretrained parameters, and performs no optimization, fitting, or parameter search. Training data were used only for a labeled PNG montage, class-count summary, and five logged checks on one fixed randomly selected 1,500-image subset. No pixels, image measurements, class averages, or computed dataset statistics were copied into weights. The five checks prompted sequential implementation and robustness revisions; the submission is the final revision, not the earlier revision with the highest checked accuracy.

The final permitted check obtained 0.2393 accuracy on that subset (chance-adjusted score approximately 0.1548). This is a training-subset diagnostic, not a held-out result, and does not establish that this hand-designed model beats either comparison baseline. No further image-based evaluation was run after the fifth check.

Reproduce the artifacts with `python3 build.py OUTPUT_DIRECTORY`. The program writes network.json and weights.npz without needing any other project files or data.
