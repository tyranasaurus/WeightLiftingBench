The network is a hand-engineered, multi-branch template matcher. It normalizes the input for illumination, then computes normalized RGB, normalized greyscale, red/blue/yellow colour-opponent responses, and eight unsigned Sobel orientation maps at 16 x 16 resolution. A fifth branch correlates the orientation maps with centre-masked templates to emphasize each sign's pictogram.

I drew all 43 signs with a small supersampled vector renderer using general German traffic-sign geometry: circular and triangular borders, stroke digits, vehicles, pedestrians, arrows, and other standard symbols. Seven independently drawn scale/translation variants per class provide limited geometric tolerance. Each generated template is normalized using only its own values; templates are never averaged and no cross-image statistic is used. Dense layers perform template correlations, max-pooling selects the best variant for each class, and hand-chosen branch weights sum the evidence into 43 scores.

No training data, image measurements, learned parameters, external fonts, or files are used by `build.py`. The submitted design is the best of the five permitted complete training-set checks (43.86% training accuracy); this number is only a check result, not an estimate of held-out accuracy.
