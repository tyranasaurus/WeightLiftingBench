I wrote Bézier pen paths for common ways of writing each digit and used a fixed seed to vary their proportions, bends, stroke width and slant. Each rasterized drawing is a separate template: no drawings are averaged, and no training images, fonts, or fitted weights are used in the build. At inference, each image is individually deskewed and normalized, then compared with the templates using oriented edge responses, enclosed whitespace, and indentations open to each side. A second comparison of the shortlisted templates allows neighboring patches to shift by one cell in either direction; it checks the match both from template to input and from input to template.
