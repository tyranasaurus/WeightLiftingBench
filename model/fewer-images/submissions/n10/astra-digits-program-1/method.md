The classifier compares each digit with individual drawings made by a seeded pen model. I wrote the lines, Bézier curves, loops, and common writing variants for each numeral from general knowledge; the builder varies pen pressure and geometry and never reads an image file. Each drawing is deskewed and described independently using oriented ink edges, ink density, enclosed paper, and directional notches. At prediction time the program takes a shortlist for each class, compares local patches with a small displacement allowance, and returns the class with the lowest combined matching cost. No template, feature weight, or decision rule was fitted to data.
