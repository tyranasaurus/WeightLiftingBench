The network compares smoothed ink density, oriented edges, and the gaps bracketed by ink along horizontal, vertical, and diagonal lines. Each matched filter represents one drawing made from hand-authored Bézier pen paths, with fixed-seed variations in slant, width, curvature, and pen pressure. Each drawing is centered and normalized independently; no filter combines drawings or uses the supplied examples. For each class the network combines the strongest joint match with the average of the best matches in eight groups. A separate, hand-weighted branch propagates exterior background around the ink and checks for enclosed spaces above or below the middle, including two spaces separated by ink, to help distinguish digits such as 0 and 8.
