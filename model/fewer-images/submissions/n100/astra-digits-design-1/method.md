The digit models are hand-written pen paths: lines and Bézier curves describe different ways to write each numeral. A fixed-seed pen varies width, slant, proportions, and curvature, then scales each drawing to a 20-pixel box and centers it by its own ink mass. Each drawing supplies one template, split into four independently computed feature blocks: blurred ink, locally pooled directional edges, background bounded by opposing ink rays, and enclosure evidence. The network applies the same fixed operators to the input, compares it with each template by normalized correlations, and gives each class a score combining its best match with the best matches from eight disjoint groups. No training examples, fonts, learned filters, or statistics across drawings are used to construct the weights.
