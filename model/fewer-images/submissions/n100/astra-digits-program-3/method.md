The template source is a set of hand-authored Bézier pen paths: for example, the four can be open or triangular, and the seven can have a crossbar. A fixed-seed renderer varies curvature, slant, width, and pen pressure. Each of its 34,560 drawings supplies one template, normalized independently; no training images, fonts, or statistics across drawings are used to construct the bank.

The recognizer deskews each input using its ink moments and puts it in a common coordinate frame using ink-mass quantiles. It shortlists templates by pooled edge directions, ink coverage, aspect ratio, and the locations of enclosed spaces. The final comparison lets small patches shift locally and checks the thinned stroke centerlines, endpoints, and junctions before returning the best-matching digit class.
