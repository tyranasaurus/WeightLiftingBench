The program locates the central galaxy, subtracts the local sky level, and traces equal-brightness contours to estimate its apparent size, orientation, and flattening. Two resolved nuclei with light between them suggest a merger; a lopsided connected envelope or a persistent one-sided plume suggests a disturbed galaxy. For discs, it measures how light winds around elliptical rings, whether the central elongation stays straight like a bar, and whether an edge-on disc thickens into a central bulge. Cross-band agreement helps distinguish faint structure from sky noise.

I wrote the filters, geometric measurements, and decision rules by hand, using unaltered class sheets for qualitative inspection and the official labeled checks to identify failure modes. Each decision uses only the input image. The builder writes the source directly, with no data files, learned parameters, stored examples, or separate constants archive.
