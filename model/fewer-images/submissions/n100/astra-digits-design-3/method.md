The builder draws each digit from hand-written curves and line segments, varying stroke width, proportions, slant, bending, and details such as whether a seven is crossed. It scales each drawing to the stated digit size and centers it by its own ink mass. The network compares four views of a query to each individual drawing: blurred ink, signed directional edges, background pockets bounded by ink on several sides, and enclosed space. For the last view, a soft flood fill starts at the image border; a point inside a closed loop is harder to reach than one in an open recess. Each view is normalized using that drawing alone; the class score is the mean of the best joint matches in six disjoint groups. All pen paths, filters, mixture coefficients, and random seeds are specified in the builder; no training data are used to make the weights.
