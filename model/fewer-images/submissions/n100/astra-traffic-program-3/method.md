The classifier searches for the sign's center, width and height using geometric outlines, opponent colors and brightness edges. It samples the interior of each plausible outline and compares it with individual hand-drawn pictograms using intensity correlation, local part comparisons and pooled gradient directions. Speed limits have a second reader that matches individual digits on a common baseline; small color-region tests distinguish details such as traffic lights and the red overtaking vehicle.

The builder draws the shapes from polygons, curves and strokes, without fonts or other input files. Each template is normalized only against itself; no photographs, statistics from photographs or fitted weights are stored. The supplied photos were used for visual inspection and the logged sandbox checks.
