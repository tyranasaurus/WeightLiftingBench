The network compares overlapping cells of signed edges, unsigned edges, center-surround responses, and broad shading, after normalizing each input channel. Each template describes one rendering of a tapered palm and forearm, four three-link fingers, and an opposable thumb, posed by hand-written ASL rules. A fixed-seed generator varies proportions, perspective, framing, and lighting; each rendering is normalized separately. The matcher allows a small lower-hand displacement while preserving the same template for both regions. Each class score combines its best response with the mean of the best responses in four fixed groups, computed on the input at inference. All filters and placement maps are analytic, and the builder reads no photos, labels, or other files.
