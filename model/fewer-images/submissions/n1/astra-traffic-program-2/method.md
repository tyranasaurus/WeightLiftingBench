The classifier searches for the geometry of a sign before trying to read it. It compares polygon and circle stencils at several sizes, centers, and slants using log-color ratios, brightness, and edges, then checks the candidate face for features such as a red rim, a continuous cancellation slash, or a white bar. Inside the rectified face it matches individually rendered digits and pictograms using normalized intensity correlation, center-surround contrast, and oriented edges; a separate character matcher reads ambiguous speed limits. The drawings, pen paths, pose ranges, and filters are specified by hand in `build.py`. Each template is normalized independently, and the builder uses no image files, training, or external assets.
