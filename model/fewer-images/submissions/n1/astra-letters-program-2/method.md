`build.py` describes the static ASL alphabet with a palm, wrist, thumb, and jointed fingers in anatomical coordinates. It uses fixed-seed variation in pose, proportions, camera framing, and light to render individual templates, using both a three-dimensional hand and a simpler projected construction for variation in finger overlap. Each template is processed independently: the descriptor combines unsigned oriented edges, a border-to-interior path-cost cue, and signed local shading. `predict` first compares coarse descriptors, then checks the shortlisted templates using overlapping patches that can move by one cell. No photographs, labels, learned parameters, or statistics across rendered images are used to build the template bank.
