The builder draws digits from hand-written spline paths, including alternatives such as open and closed fours and crossed and uncrossed sevens. A fixed seed varies the pen pressure, stroke width, slant, and curvature. Each drawing contributes one independently normalized template; the builder neither reads example images nor estimates any quantity across drawings.

For recognition, `predict` corrects slant using the input digit's ink moments and rescales its outline. It shortlists templates in each class using pooled edge directions and ink density, then compares enclosed spaces at three grey levels and allows local patches to shift by up to one grid cell. It returns the digit of the lowest-cost individual match. The supplied labeled examples were reserved for a sandbox check, not for designing the paths or choosing settings.
