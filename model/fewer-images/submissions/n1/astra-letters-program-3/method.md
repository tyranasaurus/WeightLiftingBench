I specified the 24 ASL letters as poses of one articulated hand: four three-joint fingers, an opposable thumb, a tapered palm and a forearm. The data-free builder renders those poses with fixed variations in articulation, camera angle, crop, proportions and lighting. Each rendering contributes only its own normalized template; no weights or statistics are fitted across images. At prediction time the program estimates foreground using both border brightness and the weakest edge barrier on a path to the frame. It compares foreground, oriented edges and local shading on a coarse grid, then checks the most promising templates for each letter on a finer grid.
