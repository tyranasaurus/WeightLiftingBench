I wrote pen paths for each digit, including alternatives such as a looped-foot 2, an open or closed 4, and a crossed 7. A fixed-seed renderer varies the knots, proportions, slant, rotation, and pen pressure, then scales and centers each drawing independently. The network compares the input with each drawing using contrast-normalized ink, pooled directional edges, clear lines of sight, and a cavity map found by propagating background inward from the border. Each drawing sets only its own template row and squared-distance bias; the class score combines the strongest match with the mean of four group maxima. No training examples, fitting, or comparisons between rendered drawings are used to construct the weights.
