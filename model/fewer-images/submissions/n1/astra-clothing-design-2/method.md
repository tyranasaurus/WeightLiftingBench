The main branch compares each input with 1,920 separate hand-parameterized drawings per class. It uses a soft foreground mask, its contours, and grayscale shading; each template is centered and normalized using only its own pixels. The class score combines the best match with the best match in each of four fixed groups, so it rewards a silhouette that matches more than one drawing. Two smaller branches look for a center-front opening on clothing and negative space between shoe straps. All shapes, filters, and scoring rules come from garment geometry and fixed constants in `build.py`; no examples were used to fit the weights or select settings.
