The classifier first searches for a sign’s frame using hand-specified shape, colour-contrast and edge filters at different positions and scales. It refines the pose, corrects exposure within the sign face, and checks that the expected frame colour is present around the perimeter. It then compares the interior with individually rendered vector sketches using intensity, local contrast and oriented gradients. Speed limits also get a character-by-character reading, and warning pictograms get a two-way stroke-overlap check so that both missing and extra strokes count against a match.

The rebuild program draws each template from geometric primitives and normalizes it independently. It reads no images, fonts, or model files and performs no training. The 43 supplied photographs were used for visual inspection and four official labeled checks, not to generate constants. The final check classified 34 of 43 correctly; this is not a measurement of hidden-set accuracy.
